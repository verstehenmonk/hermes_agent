# SOP: Launch Announcement

Run when a Notion spec moves to `shipped` AND the launch checklist is green.

## Artifacts (all four are DRAFTS)

### 1. Blog post
- 600–1200 words
- Structure: problem → why now → what we built → how it works (2-3
  screenshots) → who it's for → how to try it
- Footnote any claims with data
- Voice: matches `business/knowledge-base/company.md`

### 2. X thread (5–9 tweets)
- Tweet 1: hook + screenshot/loom (no link)
- Tweets 2-N: one tweet per key idea, screenshots inline
- Last tweet: link to blog
- No quoted-tweet-of-the-thread-self-promo gimmicks

### 3. LinkedIn post
- 1200–2000 chars
- Hook in first line
- Native carousel (5-7 frames) if visual material allows
- Link to blog at the bottom

### 4. Customer email
- Subject ≤ 50 chars
- Plain text, addressed by first name (use Gmail merge if needed)
- 3 paragraphs: what shipped, what it does for them, one-click CTA
- Segment: only customers on plans where the feature is enabled

## Output

Post all four DRAFTS as a single thread in `#marketing`. Founder approves
each individually. Schedule sends for staggered times (blog publishes first,
then X 30 min later, then LinkedIn 1h later, then email 2h later — give the
blog time to settle for inbound link).
